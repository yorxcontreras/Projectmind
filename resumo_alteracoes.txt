Data: 26/10/2026

1. PROBLEMAS IDENTIFICADOS
--------------------------------------------------------------------
- O formulario de cadastro no Frontend (CadastroPage.jsx) nao capturava
  os campos (nome, email, senha) nem realizava chamada HTTP para o backend,
  apenas redirecionava para a tela de login.
- O formulario de login (LoginPage.jsx) possuia dados mocados fixos
  ("Maria Silva") e nao consultava a API do backend.
- O servico authService.js estava apontando para rotas legadas (/api/auth/login
  e /api/auth/register) que possuiam retornos ficticios.
- A entidade Usuario.java nao protegia o campo senha na serializacao JSON
  e podia gerar problemas de lazy loading/ciclo na relacao com Projetos.
- Havia um caractere invalido (aspas simples na linha 155) no script
  mvnw.cmd que impedia o Maven Wrapper de compilar.
- O pacote lucide-react nao estava instalado no node_modules do frontend.


2. ALTERACOES REALIZADAS NO BACKEND
--------------------------------------------------------------------
a) Entidade Usuario (com.projectmind.domain.Usuario):
   - Adicionada a anotacao @JsonProperty(access = Access.WRITE_ONLY)
     no campo 'senha' para permitir o recebimento da senha no cadastro/login,
     mas nunca expor a senha nas respostas JSON da API.
   - Adicionada a anotacao @JsonIgnore no campo 'projetos' para evitar
     loops de serializacao e erros de sessao JPA.

b) Servico de Usuario (com.projectmind.service.UsuarioService):
   - Metodo cadastrar(Usuario usuario):
     * Valida campos obrigatorios (nome, email, senha).
     * Normaliza e-mail (trim e minusculo).
     * Verifica se o e-mail ja existe antes de salvar.
     * Salva o usuario no banco de dados via UsuarioRepository.
   - Metodo fazerLogin(String email, String senha):
     * Valida credenciais recebidas.
     * Busca o usuario por e-mail e confere a senha.
     * Lanca excecao clara caso as credenciais sejam invalidas.
   - Metodos auxiliares adicionados: listarTodos(), buscarPorId() e buscarPorEmail().

c) Controller de Usuario (com.projectmind.controller.UsuarioController):
   - POST /api/usuarios e POST /api/usuarios/cadastro:
     * Recebe { "nome": "...", "email": "...", "senha": "..." }
     * Retorna HTTP 201 Created com { id, userId, nome, email, message }.
   - POST /api/usuarios/login:
     * Recebe { "email": "usuario@email.com", "senha": "suasenhasecreta" }
     * Retorna HTTP 200 OK com { id, userId, nome, email, token, message }.
     * Em caso de erro, retorna HTTP 401 Unauthorized com { erro: "..." }.
   - GET /api/usuarios: Lista usuarios cadastrados.
   - GET /api/usuarios/{id}: Busca usuario por identificador.

d) Integracao do AuthController (com.projectmind.controller.AuthController):
   - Atualizado para delegar o login e o registro ao UsuarioService,
     garantindo consistencia caso qualquer chamada utilize /api/auth/*.

e) Correcao do Wrapper Maven (mvnw.cmd):
   - Removido caractere espurio que impedia o comando de build.


3. ALTERACOES REALIZADAS NO FRONTEND
--------------------------------------------------------------------
a) Servico de Autenticacao (frontend/src/services/authService.js):
   - Metodo login({ email, senha }):
     * Aponta agora para: POST /api/usuarios/login
   - Metodo register({ nome, email, senha }):
     * Aponta agora para: POST /api/usuarios/cadastro

b) Pagina de Cadastro (frontend/src/pages/CadastroPage.jsx):
   - Adicionados estados para os inputs (nome, email, senha).
   - Conectado com o register() do authService.
   - Adicionado alerta de erro para falhas de validacao ou e-mail duplicado.
   - Adicionado alerta de sucesso e indicador visual de salvamento (spinner).

c) Pagina de Login (frontend/src/pages/LoginPage.jsx):
   - Conectado com o login() do authService enviando { email, senha }.
   - Adicionado tratamento de erro para credenciais invalidas.
   - Adicionado estado de carregamento ao clicar em 'Entrar'.
   - Salva a sessao no contexto de autenticacao e redireciona para /projetos.

d) Contexto de Autenticacao (frontend/src/context/AuthContext.jsx):
   - Implementada a persistencia no localStorage (chaves 'pm_user' e 'pm_token').
   - Ao recarregar o navegador (F5), a sessao do usuario nao e mais perdida.
   - Funcao logout() limpa o estado e o localStorage.

e) Cabecalhos e Telas do Sistema:
   - MeusProjetosPage.jsx, ProjetoPage.jsx e ChatPage.jsx atualizados para
     exibir o nome do usuario logado dinamicamente e conectar o botao "Sair"
     a funcao logout() que redireciona para a tela de login.

f) Dependencias:
   - Instalado o pacote lucide-react no node_modules do frontend.
